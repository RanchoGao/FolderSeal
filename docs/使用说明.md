# 密封夹（FolderSeal）使用说明

普通启动直接进入首页，不弹密码框、不展示列表或自动扫描。每次进入“我的加密文件夹”都要验证密码。在同一次列表操作中选资料打开，无需再输一次。关闭列表或完成打开后，本次授权结束。保存并锁定后再次解锁，须重新验证。

密封夹（FolderSeal）— 你的文件，只有你能打开。

作者：EurekaGao。软件在本机处理文件，不上传文件或密码；仅为检测升级访问 GitHub 的公开版本信息。加密实现与安全限制见[安全边界](安全边界.md)。

## 安装与启动

左下角“检测升级”可手动查询新安装包，启动时也会在后台检测一次。发现新版后显示版本链接，点击确认后通过浏览器下载。无新版或启动检测失败时不弹窗；手动查询失败可稍后重试。已公开的预发布版会明确标注，未上传的本地安装包不会被检测到。安装前先保存并锁定、正常退出；软件不会自动安装。

安装包为 `FolderSeal-<版本>-Setup.exe`，安装步骤见[安装说明](安装说明.md)。安装后从开始菜单 `EurekaGao → 密封夹` 打开。

不便安装时，请解压便携包后运行 `FolderSeal.exe`。建议放在稳定位置。已有快捷入口失效时，可在列表中查找资料，或用“选择已有文件夹”打开。

每次启动都需要管理员授权，不只是第一次。

## 密码与我的加密文件夹

一个密码用于打开所有新建和已统一密码的加密文件夹。旧文件夹首次打开时，需要先输入原密码完成统一。

首次设置密码至少需要 15 个字符，建议用密码管理器生成独立长密码。已有密码仍可使用，升级不会自动加长短密码。验证前不显示加密文件夹列表。忘记密码无法恢复，请单独妥善保管。

首次进入“我的加密文件夹”会后台扫描所有已就绪的本机 NTFS 固定磁盘，找到的位置立即显示，可以取消。扫描完成或取消后，加密保存位置；以后通过验证打开列表时直接显示记录，不自动重复全盘扫描。手动打开和新建的文件夹也会自动记住。

支持按名称或路径搜索、“重新扫描”和“选择位置扫描”。U 盘与移动硬盘通过选择位置补充。无权限、链接、联接点、未下载的云端占位文件等位置会跳过，结束时显示跳过数量。取消或存在跳过项时不能视为已找到全部目录；失效记录保留并标记“位置不可用”。

位置记录在 `%LOCALAPPDATA%\EurekaGao\FolderSeal\catalog.egcatalog`，使用密码加密。复制便携版程序不会自动复制位置记录，目录表也不代替密文备份。

列表自动排除回收站与开发测试生成的样例目录；旧版缓存中的这些记录会在登录时清理并保存，无需重新全盘扫描。这里只移除记录，不删除磁盘文件。未统一密码的真实旧目录和暂时不可用的真实位置仍保留。

扫描发现的旧文件夹显示“待接入”。首次打开时，确认改密并输入原密码，将当前快照和目录内“上一版本”分别改用当前密码，保留各自内容。完成后原密码失效；外部副本及备份不自动改密，仍用各自原密码。接入前如有未恢复工作区，先在“更多”中恢复、保存并锁定。

改密只在密文流之间转换，不生成临时明文文件。中断后用同一密码再次打开目录，程序先恢复事务，再允许编辑。请保留 `.pending-*` 文件，不要用旧版本操作尚未完成改密的目录。遇到损坏、空间不足或占用时停止并保留原数据，排除原因后重试。

## 创建加密文件夹

1. 点击“创建加密文件夹”，选择上级目录，给加密文件夹命名。
2. 创建时验证密码，新文件夹使用同一个密码，无需另设密码。
3. 程序创建工作区并生成初始密文。创建完成后处于锁定状态；资料可从“我的加密文件夹”集中打开。

文件夹位置由你选择。每个目录使用独立随机盐与派生密钥。若上级目录的权限允许普通用户绕过保护移动整个目录，程序会拒绝在该位置创建，请换一个位置。

## 导入、编辑与锁定

1. 验证后可在本次“我的加密文件夹”列表操作中直接选资料打开。再次打开列表、点击「解锁」、使用「选择已有文件夹」或资源管理器入口时，均需验证。
2. 点击“打开所在文件夹”，在资源管理器中查看、编辑、粘贴或拖入文件；也可以用“导入文件”“导入文件夹”，这两个按钮默认保留源文件。
3. 关闭正在编辑文件的程序，再点击“保存并锁定”。看到“已锁定”才算保存和明文清理完成。

解锁后也可以直接双击文件列表中的文件，或选中后按 Enter，使用 Windows 默认关联程序打开。编辑结束后仍需先保存并关闭文件，再回到软件保存并锁定。

退出时若仍处于解锁状态，软件会要求先保存并锁定；无法保存时会保留工作区并阻止正常退出。关闭资源管理器窗口不会自动锁定。

## 删除与防误删

- 已加密并锁定的资料只允许具备相应权限的管理员或 Windows 系统访问密文目录。普通权限运行的资源管理器、AI 和其他程序无法列出目录内容、打开密文、覆盖或删除。目录名称仍可能在上级目录中显示。
- 软件退出后 NTFS 权限依然生效。旧版已有目录在本版首次成功解锁或保存时更新权限。
- 正式删除：选择加密文件夹，先锁定，在“更多”中选择“删除加密文件夹…”，确认后再次输入密码。删除不进入回收站。
- 加密目录的限制始终保留。解锁后，请通过密封夹打开临时编辑区，再用 Word、Excel 等程序查看和修改。以同一 Windows 账户运行的 AI 或其他程序也可能访问这个明文编辑区。
- **管理员可通过接管所有权和修改权限强制删除；格式化磁盘不受保护。加密不能代替备份。**

程序不会修改加密目录上级目录的权限，也不会改动其他已有文件夹的权限。

## 保存失败与异常退出

编辑器可能仍占用文件。遇到提示时先关闭编辑器，再重试“保存并锁定”。

程序区分“保存未完成”和“密文已保存但明文清理未完成”。后者会禁止继续导入和编辑，只重试清理，防止用部分清理的内容覆盖完整密文。

断电、强制结束进程或系统崩溃可能留下明文工作区，位置为当前用户的：

```text
%LOCALAPPDATA%\EurekaGao\FolderSeal\Sessions\随机编号\编辑区
```

重启软件会提醒恢复。选择对应加密目录，程序会停在锁定状态。在“更多”中选择“恢复未锁定工作区”，按时间和状态选中记录，验证后检查内容并保存锁定。

若当前加密版本与工作区的来源版本不同，或旧版工作区没有来源记录，程序会保留两份内容。按提示复制旧编辑区中所需的文件，导入另一个加密文件夹，检查后保存并锁定。确认新版和旧版内容都已妥善保留前，请保留原工作区。

遗留工作区不具备“每次访问都要密码”的保护，同一个 Windows 账户能够访问它。

## 密文与备份

每个加密文件夹包含：

- `内容.egvault`：当前加密快照，包含内容、文件名和目录结构。
- `上一版本.egvault`：上次成功保存的快照，同样加密，可能包含刚删除或修改前的旧内容。
- `.access.lock`：防止两个程序同时编辑同一加密目录的标记。

请在锁定后用管理员权限的备份工具复制整个加密目录，并单独保管密码。至少留一份加密备份在备份后断开的移动硬盘上，并用样例确认能恢复。目录内的「上一版本」和当前版本位于同一设备。不要手动删除或改写密文文件。

若当前密文损坏而上一版本完好，可在备份整个目录后，由管理员将 `上一版本.egvault` 复制为 `内容.egvault` 再尝试解锁；这会丢失上一版本之后的修改。

**忘记密码无法恢复。** 软件没有后门或联网找回功能。

## 文件夹图标入口

已有文件夹图标快捷方式仍可使用，本版从“我的加密文件夹”集中打开资料。双击入口时独立验证密码，即使已验证过列表也需要输入。

- 快捷方式不是数据本体，删除快捷方式不会删除密文；备份必须包含隐藏的密文目录。
- 入口绑定创建它的程序路径；移动便携程序后入口可能失效，安装版更稳定。
- 程序拒绝覆盖已有同名入口。入口失效时可在软件中选择真实密文目录继续访问。

## 支持范围

Windows 10/11、.NET Framework 4.7.2 或更新版本、本机 NTFS 磁盘、同一 Windows 管理员账户使用。

不支持网络共享、符号链接、目录联接、硬链接和需要透明占位处理的云端文件。路径过长或不安全的文件名会被拒绝。大文件夹每次锁定会重新生成整个快照，耗时与内容大小有关。

本项目尚未经过独立安全审计。请先用测试副本验证流程，再存放唯一的重要资料。

## 自行验证

在项目根目录打开 PowerShell：

```powershell
.\scripts\build.ps1 -Validate -ValidateEntry
```

管理员终端可另外运行防删除集成测试，测试只操作新生成的样例目录：

```powershell
.\scripts\build.ps1 -ValidateAcl
```

测试密码只用于随机生成的样例，不是你的密码。


## 界面与快捷操作

创建入口只在左侧；右侧展示当前文件夹内的文件。选中资料后，顶部一行显示名称、锁定状态和解锁或保存按钮。编辑期间不能切换文件夹；待清理时不能继续导入和打开编辑区。

Alt + L 可保存或重试锁定；操作前先在编辑器中保存并关闭文件。点击左侧底部“使用帮助与异常恢复”可查看失败处理、恢复与备份方法。

单窗口运行：
同一 Windows 用户会话中只保留一个主窗口。重复打开软件会唤回已有窗口；图标入口将资料路径交给已有窗口，不再留下第二个主窗口。同一已解锁资料使用原编辑区。
当前资料未保存锁定、处理中或正在输入密码时，不会自动切换到其他资料。先完成当前操作，再重新打开入口。
从旧版本升级前，请在所有旧窗口保存并锁定，然后正常退出。不要删除 .access.lock；若其他进程仍占用资料，按提示在原窗口保存锁定后重试。
