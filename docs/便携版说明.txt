密封夹（FolderSeal）· 便携版

普通启动直接进入首页。每次查看“我的加密文件夹”都要验证密码，本次列表中选资料打开无需再输一次。关闭列表、完成打开或保存并锁定后，下次访问重新验证。首次设置密码至少需要 8 个字符，已有密码仍可使用。

密封夹（FolderSeal）— 你的文件，只有你能打开。
作者：EurekaGao

一、运行
先把整个压缩包解压到一个稳定位置，再双击 FolderSeal.exe。
每次运行都需要 Windows 管理员授权。
要求 Windows 10/11、.NET Framework 4.7.2 或更新运行时、本机 NTFS 磁盘。
无需安装，不上传文件或密码；仅为检测升级访问GitHub公开版本信息。不要直接在压缩包内部运行程序。

启动后后台检测新安装包，左下角也可点击“检测升级”。发现新版后点击确认：若存在已解锁资料先引导保存并锁定，随后在应用内进度窗口下载安装包并强制校验大小与 SHA-256；校验通过后便携版自动退出并拉起安装向导（不静默覆盖）。缺少校验文件或下载失败时停止自动安装，支持重试或浏览器兜底；预发布版会明确标注。

二、已有资料
首次访问需要密码的功能时设置一个密码（至少 8 字符，可填写可选密码提示，提示明文保存在 settings.txt），用于打开所有新建和已统一密码的加密文件夹。“我的加密文件夹”首次扫描本机固定磁盘并记住位置，以后验证后直接显示列表，最近成功解锁的文件夹排在前面。点“按路径打开”可粘贴路径或浏览。列表还支持重新扫描及选择位置扫描。
可在侧栏底部“右键菜单与设置 → 修改密码…”批量修改统一密码（离线目录标为待接入，下次打开输原密码统一）。
旧目录首次接入需输入原密码，当前与上一版本快照改用当前密码，原密码失效；外部备份仍使用原密码。
本版保留密文格式。首次使用新版时，建议先备份并使用副本验证。改密中断后请用同一密码再次打开恢复，不要删除 .pending-* 文件。
不要删除、覆盖原密文目录，也不要把程序复制到密文目录中。

三、日常使用
进入首页 → 点击创建或查看列表并验证密码 → 打开文件夹 → 打开编辑区 → 用原有软件编辑（首页支持拖放原地加密，解锁后支持按钮或拖放导入）。
在编辑器中保存并关闭文件后，回到软件点击“保存并锁定”。
仅关闭资源管理器不会锁定；看到“已锁定”或“已快速锁定”才表示保存及明文清理均完成。
通过“导入文件”“导入文件夹”或拖放导入的资料，保存并锁定核验密文后，若原位置明文未变更且编辑区副本未被移除或替换，程序会永久删除原位置明文（不进入回收站）；否则保留原文件并提示。
快捷键 Alt + L 保存或重试锁定；左侧“使用帮助与异常恢复”可查看完整处理方法。

四、保存失败与恢复
遇到失败先保留工作区，关闭可能占用文件的程序，再重试。
“密文已保存，但明文尚未清理完”时只重试清理，不重新生成密文。
异常退出后，选择对应加密目录，在“更多”中选择“恢复未锁定工作区”，按时间和状态选择记录，核对后保存锁定。来源版本不同或缺失时，请按提示将所需文件复制到另一个加密文件夹。

五、保护边界
忘记密码无法找回。锁定后，程序对密文目录、密文文件与快捷入口同时施加普通用户与管理员显式拒绝删除（Deny Delete）保护，普通程序及管理员常规删除、改名或移动均会被拒绝；请用管理员权限的备份工具备份整个密文目录，包含隐藏目录。
默认新建或右键加密后原位置显示密封夹图标；也可在“右键菜单与设置”开启“加密后隐藏文件夹入口”或在锁定后选择“更多 → 隐藏密封夹入口…”。移动便携程序导致入口失效时，可从列表打开并锁定资料，再到“更多”中创建或修复入口。备份需包含隐藏的密文目录。
若忘记密码且确认放弃数据，管理员需先在管理员终端执行 icacls "<路径>" /remove:d Administrators 与 icacls "<路径>" /remove:d "%USERNAME%" 移除拒绝规则后再手动删除。明文采用普通删除，不保证清除历史残留。
软件尚未经过独立安全审计。请先用样例和副本验证，再存放重要资料。

单窗口运行：
同一 Windows 用户会话中只保留一个主窗口。重复打开软件会唤回已有窗口；图标入口将资料路径交给已有窗口，不再留下第二个主窗口。同一已解锁资料使用原编辑区。
当前资料未保存锁定、处理中或正在输入密码时，不会自动切换到其他资料。先完成当前操作，再重新打开入口。
从旧版本升级前，请在所有旧窗口保存并锁定，然后正常退出。不要删除 .access.lock；若其他进程仍占用资料，按提示在原窗口保存锁定后重试。
