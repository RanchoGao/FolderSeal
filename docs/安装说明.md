# 安装、升级与卸载

安装包文件名固定为 `FolderSeal-<版本>-Setup.exe`，随版本变化只改版本号。双击后按简体中文向导安装，默认位置为 Program Files 下的 `EurekaGao\FolderSeal`，也可以选择其他空目录。

安装后从开始菜单 `EurekaGao → 文件夹加密工具` 打开；安装时可另外勾选桌面快捷方式。安装程序和软件运行均需要管理员授权。

安装包只包含程序、安装版使用说明和卸载程序，不包含加密资料、密码或个人启动参数。

## 升级

关闭正在运行的软件，直接运行新版本安装包，选择原安装目录即可覆盖升级。直接覆盖安装不会改动加密文件夹。

## 卸载

卸载只删除程序文件和快捷方式，保留加密文件夹、遗留工作区和目录上的 NTFS 保护；重新安装后可使用原密码访问。

## 重新打包

```powershell
.\scripts\package.ps1
```

脚本会先编译源码，再调用 NSIS 生成安装包。编译器按以下顺序查找：`-NsisCompiler` 参数、`tools\nsis-3.13\makensis.exe`、系统 PATH。生成结果：

```text
artifacts/dist/FolderSeal-<版本>-Setup.exe
artifacts/dist/SHA256SUMS.txt
```

版本号只在 `installer/FolderSeal.nsi` 的 `!define VERSION` 中维护，安装包文件名、应用列表版本和文件版本都从这一处读取。

发布时把安装包和 `SHA256SUMS.txt` 复制到 `releases/<版本>/`；便携包及其校验文件也放在同一版本目录。版本标签使用 `v<版本>`，附件单独上传 GitHub Release。完整步骤见[发布流程](发布流程.md)。

NSIS 来自[官方发布目录](https://sourceforge.net/projects/nsis/files/NSIS%203/3.13/)，原始版权和许可保留在 `tools/nsis-3.13/COPYING`。

## 安装与卸载验证

在管理员 PowerShell 中运行：

```powershell
.\scripts\verify-installer.ps1
```

脚本在 `artifacts/` 下新建临时目录，覆盖中文和空格路径、程序哈希、应用列表版本、快捷方式、重复安装和卸载保留非程序资料。若机器已有正式安装，脚本会停止，以免影响现有软件。结果写入 `artifacts/installer-test.json`。

安装包没有商业代码签名证书，Windows 可能显示“未知发布者”。软件的行为边界见[使用说明](使用说明.md)和[安全边界](安全边界.md)。
