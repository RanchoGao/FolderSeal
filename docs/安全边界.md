# 密封夹（FolderSeal）安全边界

本文件说明软件能保护什么、不能保护什么。完整使用流程见[使用说明](使用说明.md)。

## 加密实现

- AES-256-CBC 加密文件快照；HMAC-SHA256 对数据做完整性认证，先认证完整密文，再解密。
- PBKDF2-HMAC-SHA256 将密码派生为密钥：新建快照使用 600,000 次迭代和随机 32 字节盐，加密密钥与认证密钥分开。
- 每次保存生成新的随机 IV（初始化向量，用于使相同内容的加密结果不同）。
- 保存时先生成新密文，解密并逐文件核对 SHA-256，再替换当前快照。
- 拒绝不安全的归档路径、链接、并发编辑和外部快照变化。
- 位置目录表加密并认证。密码只供当前验证及相关操作使用，完成或取消后释放密码引用和明文目录表。活动编辑会话使用所选资料的派生密钥，密文提交且清理状态已记录后清理密钥。程序不会以明文保存密码。
- 首次设置密码至少需要 8 个字符。旧密码和既有密文继续兼容；弱密码的离线猜测风险仍然存在。
- 可选“密码提示”（最多 100 字符，禁止包含密码本身）以明文保存在当前用户的 `%LOCALAPPDATA%\EurekaGao\FolderSeal\settings.txt`，同一 Windows 账户可读取；它不是密码找回机制，请勿填写密码片段或高敏感信息。
- 新建和已接入的目录共用密码，各自保留独立随机盐与派生密钥。密码泄露会影响所有使用该密码的目录。
- 旧目录接入与修改统一密码均会重新加密当前及上一版本快照；离线目录与外部备份不自动改密。改密采用加密流转换、验证、逐文件原子替换和加密事务记录；中断后先恢复，禁止直接编辑。批量修改密码时，若所有目录均未更新成功则目录表保持原密码；一旦首个目录切换成功即更新目录表并将未完成目录标为待接入，确保任意中断点可安全恢复。
- 扫描只识别候选目录的文件名和文件头，不能代替解锁时的完整密文认证。无法访问的位置不属于已确认扫描范围。

## 必须理解的限制

- 检测升级会通过 HTTPS 访问 GitHub 公开版本接口，不上传文件、文件夹路径或密码。只接受本仓库对应版本的安装包下载地址与可信重定向；应用内下载落地到仅管理员与 SYSTEM 可写的 `%ProgramData%\EurekaGao\FolderSeal\Updates`，强制校验文件大小与 `SHA256SUMS.txt`（缺少校验文件或校验不通过时停止自动更新），并在启动静默覆盖安装前二次复核 SHA-256（便携版拉起交互式向导）。该机制依赖 GitHub 与项目发布账户的安全，且程序未使用商业代码签名证书，不构成独立安全审计。
- 通过“导入文件”“导入文件夹”或拖放导入后，保存并锁定完成密文核验与编辑区清理后，程序会通过原子隔离并复核哈希/目录快照的方式永久删除原位置明文（不进入回收站）；若锁定前已从编辑区移除/替换、锁定失败或原明文发生变化，则保留原文件并提示。

- **解锁期间有明文。** 同一 Windows 账户可访问编辑区；异常退出后的工作区也可能有明文。
- 解密和核验的临时文件以及工作区说明保存在管理员和系统可访问的区域。普通用户在解锁后只获编辑区权限。保存锁定时收回该权限，保存失败保留工作区并尝试恢复编辑权限。收回权限前已打开的文件句柄可能继续有效。
- 恢复普通编辑区前核对它对应的加密快照。来源不同或无法确认时，保留当前密文和旧编辑区，由用户核对并另存所需文件。
- 明文清理采用普通删除，不承诺清除 SSD 历史块、编辑器缓存、系统备份或其他历史副本。
- 程序运行中需要使用密码和密钥，不承诺清除托管运行时或系统中的全部内存副本。
- NTFS 权限限制普通进程列出、读取、写入、删除或移动受保护的密文目录及其内容，同时对密文目录本体、密文文件及快捷入口（`.lnk`）施加普通用户、管理员与 `SYSTEM` 的显式拒绝写入与拒绝删除（`Deny Write | Delete`）规则，并收紧管理员与 `SYSTEM` 的允许权限（管理员仅保留读取与权限管理位，`SYSTEM` 仅保留只读执行），阻止普通程序、管理员常规程序及系统服务的直接覆写、新建未知文件、删除、改名或移动。已经打开的文件句柄和其他位置的副本不受这次权限更新追溯限制。管理员仍可通过修改权限/接管所有权、内核驱动或脱机磁盘手段强行破坏或删除数据。
- 程序在锁定时对密文目录本体与快捷入口自身应用删除限制，保留上级目录原有权限。
- 大文件夹每次锁定重新生成整个快照，耗时与内容大小有关。
- 不支持网络共享、符号链接、目录联接、硬链接和未下载的云端占位文件。
- 本项目尚未经过独立安全审计，不宣称绝对安全。

**忘记密码无法恢复。** 软件没有后门或在线找回密码功能。加密不能代替备份，锁定后请备份整个加密目录并单独保管密码。
