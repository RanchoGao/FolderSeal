密封夹（FolderSeal）

普通启动直接进入首页。每次查看“我的加密文件夹”都要验证密码，本次列表中选资料打开无需再输一次。关闭列表、完成打开或保存并锁定后，下次访问重新验证。

密封夹（FolderSeal）— 你的文件，只有你能打开。
作者：EurekaGao

安装后，从开始菜单 EurekaGao → 密封夹 打开软件。
每次运行需要 Windows 管理员授权。软件在本机处理文件，不上传、不保存密码。

启动后在后台检测一次 GitHub 公开发布的新安装包，左下角可手动“检测升级”。发现新版后点击确认：若存在已解锁资料会先引导保存并锁定，随后在应用内进度窗口下载安装包到管理员受保护目录并强制校验大小与 SHA-256；校验通过后程序自动退出、二次核验 SHA-256 并静默覆盖安装、重启新版本。缺少校验文件或下载失败时停止自动安装，支持重试或改用浏览器兜底。检测不上传文件、路径或密码，网络失败不影响本地功能。

启动：首次设置密码至少需要 8 个字符，用于打开所有新建和已统一密码的加密文件夹；可填写可选“密码提示”（最多 100 字符、不含密码本身，明文保存于本机 settings.txt，请勿写敏感片段）。已有密码仍可使用。
查找：“我的加密文件夹”首次后台扫描本机 NTFS 固定磁盘并记住位置，以后验证后直接显示列表。最近成功解锁的文件夹排在前面。点“按路径打开”可粘贴路径或浏览。支持取消、重新扫描及选择位置扫描；移动磁盘可用选择位置扫描补充记录，不可访问的位置会跳过或标为不可用。
创建：点击“创建加密文件夹”并验证密码，再选择上级目录、填写名称（可勾选是否隐藏文件夹入口）；新文件夹使用同一个密码。首页未选择资料时也可直接拖放单个文件或文件夹原地加密。
修改统一密码：全部资料锁定后，可在侧栏底部“右键菜单与设置 → 修改密码…”验证当前密码并批量改密（纯密文流转换），同时可更新或清除密码提示；离线目录标为待接入，下次打开输原密码统一。
右键加密：安装后可在资源管理器右键文件或文件夹，选择“加密此文件（密封夹）”或“加密此文件夹（密封夹）”，输入密码后原地生成加密体并删除明文。单个文件会变成去掉扩展名的同名加密文件夹；已加密的文件夹右键可直接打开。每次右键都会请求管理员授权。不需要时可在“右键菜单与设置”中移除菜单。
访问：本次列表操作可直接选择资料打开，也可点“按路径打开”。已锁定资料再次解锁或经外部入口打开时需单独验证。切换前先保存并锁定。
旧目录接入：首次验证原密码后，当前与上一版本快照改用当前密码，原密码失效；其他位置的备份不自动改密，仍需原密码。接入前先恢复遗留工作区。
改密中断：用同一密码再次打开该目录恢复，保留 .pending-* 文件，不要用旧程序打开迁移中的目录。
位置目录表使用密码加密，保存在 %LOCALAPPDATA%\EurekaGao\FolderSeal\catalog.egcatalog。密码不以明文保存到磁盘；忘记后无法恢复。
编辑：点击“打开所在文件夹”查看、修改；也可以点击“导入文件”“导入文件夹”或直接拖放文件/文件夹到已解锁窗口导入编辑区。注意：通过导入按钮或拖放导入的资料，在“保存并锁定”完成密文核验与编辑区清理后，若原位置明文未变更且编辑区副本未被移除或替换，程序会永久删除原位置明文（不进入回收站）；否则保留原文件并提示。
锁定：先关闭正在编辑的文件，再点击“保存并锁定”。看到“已锁定”或“已快速锁定”才算保存和明文清理完成。
删除：锁定后在“更多”中选择“删除加密文件夹…”，确认并再次输入密码。永久删除不进入回收站。

请保管好密码。忘记密码无法找回。普通程序无法访问锁定的密文目录，请用管理员权限的备份工具备份整个目录。

使用边界：
1. 仅支持本机 NTFS 磁盘。加密文件夹锁定后，程序会对密文目录本体、内部密文文件及快捷入口（.lnk）同时施加普通用户与管理员的显式拒绝删除（Deny Delete）保护，阻止普通程序及管理员常规删除、改名或移动，正式删除必须在程序中验证密码。若忘记密码且确认放弃数据，管理员可在管理员终端先执行：
   icacls "<路径>" /remove:d Administrators
   icacls "<路径>" /remove:d "%USERNAME%"
   移除拒绝规则后再手动删除。格式化、系统还原和磁盘故障不在保护范围内。
2. 不支持网络共享、符号链接、目录联接、硬链接或未下载的云端占位文件。
3. 管理员仍可通过解除拒绝规则、接管所有权或格式化磁盘破坏资料；加密不能代替备份。
4. 解锁后的编辑区有明文。断电或强制结束程序可能留下工作区，不能保证此时每次访问都要求密码。
5. 明文清理是常规删除，不承诺擦除编辑器缓存、SSD 历史块或系统备份。密码提示以明文保存在 settings.txt，同一 Windows 账户可读。
6. 尚未经过独立安全审计。先用副本验证，再存放唯一的重要资料。

异常恢复：
当前用户的 %LOCALAPPDATA%\EurekaGao\FolderSeal\Sessions 中保存未完成的工作区。
重新打开程序，选择对应加密目录，在“更多”中选择“恢复未锁定工作区”，按时间和状态选择记录，验证后核对内容并保存锁定。来源版本不同或缺失时会保留两份内容，请按提示将所需文件复制到另一个加密文件夹。
不要直接删除尚未确认内容的工作区。

卸载：
在 Windows“已安装的应用”或开始菜单中选择卸载。卸载只删除程序及其快捷方式，不删除加密目录、密码或遗留工作区。
卸载后加密目录的 NTFS 保护仍然存在。重新安装本软件后，可以输入原密码继续使用。

运行环境：Windows 10/11，.NET Framework 4.7.2 或更新版本。
安装包未使用商业代码签名证书，Windows 可能显示“未知发布者”。

文件夹图标入口与隐藏入口：默认新建或右键加密后，原位置显示密封夹图标，双击验证密码后打开编辑区。也可在“右键菜单与设置”开启“加密后隐藏文件夹入口”、新建时勾选，或在锁定后选择“更多 → 隐藏密封夹入口…”（不生成 .lnk 并将密文目录设为系统隐藏，仅从“我的加密文件夹”查看）。已有资料锁定后可在“更多”中创建或修复入口。用完仍须在软件里保存并锁定；关闭资源管理器窗口不会自动锁定。
旧入口绑定生成它的程序路径，移动便携程序后可能失效。可在密封夹中手动查找资料。快捷方式不是数据本体，备份时必须包括隐藏的密文目录。


界面与快捷操作：
左侧创建或选择加密文件夹；底部提供“右键菜单与设置”“检测升级”与“使用帮助与异常恢复”。右侧未选择资料时支持拖放原地加密，解锁后支持拖放导入、实时刷新与文件名筛选。更多菜单包含恢复工作区、创建或修复/隐藏密封夹入口与删除资料。
Alt + L 保存或重试锁定。请先在编辑器中保存并关闭文件。
明文清理未完成时，点击“重试清理并锁定”，只继续清理，不重新生成密文。
左侧底部“使用帮助与异常恢复”中可查看编辑、保存失败、恢复、备份与保护边界。

单窗口运行：
同一 Windows 用户会话中只保留一个主窗口。重复打开软件会唤回已有窗口；图标入口将资料路径交给已有窗口，不再留下第二个主窗口。同一已解锁资料使用原编辑区。
当前资料未保存锁定、处理中或正在输入密码时，不会自动切换到其他资料。先完成当前操作，再重新打开入口。
从旧版本升级前，请在所有旧窗口保存并锁定，然后正常退出。不要删除 .access.lock；若其他进程仍占用资料，按提示在原窗口保存锁定后重试。
