密封夹（FolderSeal）

普通启动直接进入首页。每次查看“我的加密文件夹”都要验证密码，本次列表中选资料打开无需再输一次。关闭列表、完成打开或保存并锁定后，下次访问重新验证。

密封夹（FolderSeal）— 你的文件，只有你能打开。
作者：EurekaGao

安装后，从开始菜单 EurekaGao → 密封夹 打开软件。
每次运行需要 Windows 管理员授权。软件在本机处理文件，不上传、不保存密码。

启动后在后台检测一次GitHub公开发布的新安装包，左下角可手动“检测升级”。发现新版后点击版本链接确认下载；预发布版会明确标注。检测不上传文件、路径或密码，网络失败不影响本地功能。安装前先保存并锁定、正常退出，软件不会自动运行安装包。

启动：首次设置密码至少需要 15 个字符，用于打开所有新建和已统一密码的加密文件夹。已有密码仍可使用。
查找：“我的加密文件夹”首次后台扫描本机 NTFS 固定磁盘并记住位置，以后验证后直接显示列表；支持取消、重新扫描及选择位置扫描。移动磁盘需选择位置扫描；不可访问的位置会跳过或标为不可用。
创建：点击“创建加密文件夹”并验证密码，再选择上级目录、填写名称；新文件夹使用同一个密码。
右键加密：安装后可在资源管理器右键文件或文件夹，选择“加密此文件（密封夹）”或“加密此文件夹（密封夹）”，输入密码后原地生成加密体并删除明文。单个文件会变成去掉扩展名的同名加密文件夹；已加密的文件夹右键可直接打开。每次右键都会请求管理员授权。若所在文件夹允许普通程序移走子文件夹，会先提示风险并询问是否继续，确认后不再重复检查。不需要时可在软件“更多”中移除菜单。
访问：本次列表操作可直接选择资料打开。「解锁」、手动选择和外部入口均需单独验证。切换前先保存并锁定。
旧目录接入：首次验证原密码后，当前与上一版本快照改用当前密码，原密码失效；其他位置的备份不自动改密，仍需原密码。接入前先恢复遗留工作区。
改密中断：用同一密码再次打开该目录恢复，保留 .pending-* 文件，不要用旧程序打开迁移中的目录。
位置目录表使用密码加密，保存在 %LOCALAPPDATA%\EurekaGao\FolderSeal\catalog.egcatalog。密码不以明文保存到磁盘；忘记后无法恢复。
编辑：点击“打开所在文件夹”，查看、修改或拖入资料；也可以使用导入按钮。普通导入保留源文件。
锁定：先关闭正在编辑的文件，再点击“保存并锁定”。看到“已锁定”才算保存和明文清理完成。
删除：锁定后在“更多”中选择“删除加密文件夹…”，确认并再次输入密码。永久删除不进入回收站。

请保管好密码。忘记密码无法找回。普通程序无法访问锁定的密文目录，请用管理员权限的备份工具备份整个目录。

使用边界：
1. 仅支持本机 NTFS 磁盘。若上级目录权限允许绕过保护移动整个目录，创建前会提示风险并询问；确认后创建的加密文件夹可能被普通程序整体移走或删除，密文仍受密码保护。
2. 不支持网络共享、符号链接、目录联接、硬链接或未下载的云端占位文件。
3. 防删除针对受支持位置的常规操作。管理员接管权限、修改上级权限或格式化磁盘仍可破坏资料。
4. 解锁后的编辑区有明文。断电或强制结束程序可能留下工作区，不能保证此时每次访问都要求密码。
5. 明文清理是常规删除，不承诺擦除编辑器缓存、SSD 历史块或系统备份。
6. 这是自用初版，尚未经过独立安全审计。先用副本验证，再存放唯一的重要资料。

异常恢复：
当前用户的 %LOCALAPPDATA%\EurekaGao\FolderSeal\Sessions 中保存未完成的工作区。
重新打开程序，选择对应加密目录，在“更多”中选择“恢复未锁定工作区”，按时间和状态选择记录，验证后核对内容并保存锁定。来源版本不同或缺失时会保留两份内容，请按提示将所需文件复制到另一个加密文件夹。
不要直接删除尚未确认内容的工作区。

卸载：
在 Windows“已安装的应用”或开始菜单中选择卸载。卸载只删除程序及其快捷方式，不删除加密目录、密码或遗留工作区。
卸载后加密目录的 NTFS 保护仍然存在。重新安装本软件后，可以输入原密码继续使用。

运行环境：Windows 10/11，.NET Framework 4.7.2 或更新版本。
安装包未使用商业代码签名证书，Windows 可能显示“未知发布者”。

文件夹图标入口：已有文件夹图标快捷方式仍可使用，本版从“我的加密文件夹”集中打开资料。双击入口时独立验证密码，即使已验证过列表也需要输入。用完仍须在软件里保存并锁定；关闭资源管理器窗口不会自动锁定。
旧入口绑定生成它的程序路径，移动便携程序后可能失效。可在密封夹中手动查找资料。快捷方式不是数据本体，备份时需包括隐藏的密文目录。


界面与快捷操作：
左侧创建或选择加密文件夹；右侧以文件列表为主，选中后显示紧凑状态栏。名称悬停可查看完整路径，更多菜单包含恢复工作区、资源管理器右键菜单开关与删除资料。
Alt + L 保存或重试锁定。请先在编辑器中保存并关闭文件。
明文清理未完成时，点击“重试清理并锁定”，只继续清理，不重新生成密文。
左侧底部“使用帮助与异常恢复”中可查看编辑、保存失败、恢复、备份与保护边界。

单窗口运行：
同一 Windows 用户会话中只保留一个主窗口。重复打开软件会唤回已有窗口；图标入口将资料路径交给已有窗口，不再留下第二个主窗口。同一已解锁资料使用原编辑区。
当前资料未保存锁定、处理中或正在输入密码时，不会自动切换到其他资料。先完成当前操作，再重新打开入口。
从旧版本升级前，请在所有旧窗口保存并锁定，然后正常退出。不要删除 .access.lock；若其他进程仍占用资料，按提示在原窗口保存锁定后重试。
