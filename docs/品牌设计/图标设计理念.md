# 密封夹（FolderSeal）Icon 设计理念

- **状态**：已落地。2.2.3 起使用按此理念制作的深绿封印图标，成品见 `assets/FolderSeal.ico` 与 `assets/FolderSeal.png`。
- **维护**：设计方向调整时直接改本文，历史由 Git 保存；不新增带版本号的副本。

## 一、设计结论

密封夹（FolderSeal）的应用图标采用 **「极简、安全、可信赖」** 的设计路线，核心视觉概念为：**一个被安全封存的文件夹**。

目标是让用户直观理解：这是一款保护私人文件、同时方便日常使用的工具。

## 二、产品定位与目标用户

| 维度 | 定位 |
| --- | --- |
| 产品名称 | 密封夹（FolderSeal） |
| 产品类型 | Windows 本地文件保险箱 / 文件夹加密工具 |
| 目标用户 | 有私人文件保护需求的普通电脑用户 |
| 核心功能 | 文件加密、密码解锁、日常编辑、保存并锁定、异常恢复 |
| 核心价值 | 让私人文件安全保存，又不影响日常使用 |
| 用户心理诉求 | 安全感、掌控感、简单、省心 |

**核心判断**：FolderSeal 向用户传递的价值不仅是加密技术，更是对私人文件的掌控感。因此，Icon 应优先表达“文件受到保护”，而非 AES-256、密码学等技术细节。

## 三、核心视觉策略

### 3.1 文件夹 + 安全封存

- 以**文件夹**作为主体，使用户迅速建立文件相关的认知。
- 将**封存/闭合**融入文件夹自身的结构，形成品牌特征。
- 避免简单地在普通文件夹上叠加通用锁头，降低同质化。
- 图形应在缩小后仍具有独特且稳定的外轮廓。

### 3.2 现代极简

| 元素 | 设计要求 |
| --- | --- |
| 整体风格 | 现代、几何化、简洁 |
| 造型 | 轮廓饱满、细节克制、容易识别 |
| 主色 | 深绿色或蓝绿色 |
| 辅色 | 少量浅绿色或白色 |
| 质感 | 优先扁平化，可使用轻微渐变 |
| 文字 | Icon 内不添加名称、文案或字母 |
| 复杂度 | 尽量少的元素表达文件保护 |

配色优先延续当前产品界面的绿色品牌体系，保证界面与图标的一致性。正式出图前需以实际 UI 颜色为准进行校准。

### 3.3 安全但不沉重

图标应传递：

1. **安全**：私人文件受到保护。
2. **轻松**：日常使用并不复杂。
3. **精致**：符合现代 Windows 桌面应用观感。

避免军事化盾牌、黑客风、厚重金属锁、大量高光及复杂立体纹理。

## 四、适配场景与技术约束

图标需适配 Windows 桌面快捷方式、任务栏、开始菜单，以及文件资源管理器中的相关入口。

重点检验尺寸：**16×16、32×32、48×48、256×256**。

- 优先保证 16×16 和 32×32 下主体可辨。
- 不依赖细线、微小装饰、复杂阴影传递核心意义。
- 兼顾亮色与深色界面的对比度。
- 交付阶段应准备可缩放源文件和 Windows 所需图标规格；具体导出参数届时确认。

## 五、评价标准

| 优先级 | 标准 | 检验方式 |
| --- | --- | --- |
| P0 | 辨识度 | 缩小后仍能认出独特形状 |
| P1 | 产品关联 | 可联想到文件保护，而非普通文件管理 |
| P2 | 品牌感 | 简洁、耐看，不像通用素材 |

**设计取舍**：不要求用户仅凭 Icon 完整理解所有加密功能，但必须具有清晰、稳定、可延展的品牌识别性。

## 六、后续流程

1. **设计理念**：确认「极简、安全、文件封存」为主方向。（已确认）
2. **设计方向**：提供 3 个差异化概念，说明构成、配色、优劣和推荐排序。（进行中）
3. **高保真制作**：用户选择方向后再生成 Icon 视觉稿，并迭代。

## 七、优先探索方向

优先尝试以文件夹为基础，将 **Seal（封印 / 密封）** 通过闭合结构、边缘造型或负形融入图形本身，形成 FolderSeal 独有的视觉符号。
